# Instructions

Runtime-instruktioner för System Modeller.

- `chat-runtime.md` – primär startpunkt för Chat-ZIP v0.1.0.
- `source-analysis.md` – normativt arbetsflöde för LLM-baserad analys av dokumentation och källkod.

Metamodell, schemas och modellguider är fortsatt normativa för själva projektformatet.

- Custom GPT-runtimeen ska genereras från samma kanoniska källor enligt `templates/custom-gpt-distribution.yaml`; ingen separat handunderhållen instruktion etableras i A31.
